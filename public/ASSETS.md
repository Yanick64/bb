# Asset sources

`2digits.ico` is the official favicon, downloaded from
https://2digits.nl/favicon.ico?favicon.3w5-e6ez57qp7.ico on 29 October 2026.
It is displayed unchanged beside the 2DIGITS name and used as the browser favicon.

The font files in `fonts/` belong to the previous design. Their upstream licenses
remain alongside them. The personal workbench uses the system UI sans and does
not request these fonts.
